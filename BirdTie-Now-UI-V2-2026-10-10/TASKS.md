## 回归矩阵

| 场景 | 操作 | 必须看到/保持 | 不能发生 |
|---|---|---|---|
| 访客选择城市 | 不登录，打开/搜索/选择已有可用目的地 | 只出现地理选项；探索状态更新 | 被线上范围说明阻断、改写隐私/定位 |
| 城市目录受限 | 搜一个不在可用目录的城市 | 明确目录/可用性反馈 | 伪装全世界只有Aberdeen或未开通城市可完整使用 |
| 紧凑主页 | 无对话启动 | 满宽贴底的输入区，无空聊天占位 | 左右/底部露地图缝 |
| 地址短结果 | 查询已消歧有来源地点 | 一张名称地址卡、一个来源入口、导航/更多 | prose复述地址、来源1+pill+全部来源+来源并存 |
| 多候选 | 同名不同城/Greenhouse与Glenhouse | 地点消歧与清楚候选 | 擅自替换实体名称/地址 |
| 18个稀疏坐标 | 显示分散于可见视口且可区分地点 | 空间分布可见，逐项命中正确对象 | 按cityId全部合并成18 |
| 局部密集点 | 连续放大/点聚合 | 局部分解或成员列表；选中点明确 | 高缩放仍无意义放大或视图永远只有一个pin |
| 同场地多活动 | 一个场地关联若干活动 | 一个场地锚点、明确活动数与列表 | 为活动随机改位置或数字冒充地点数 |
| 未知/区域位置 | 传入无精确坐标条目 | 待确认或区域语义，列表可读 | city.center/0,0/首条坐标回填，假导航 |
| 权限变化 | 私密/撤回/无权限条目参与检索 | 总数与聚合均按可见项计算 | 从数字泄露不可见内容存在 |
| 系统文字放大 | 常规、大号、接近2.0 | 地址完整可读，按钮可重排、可滚动 | 禁用TextScaler、标题/邮编裁切、点击目标变小 |
| 来源不同页同域 | 多文档来源同域名 | 保留不同证据；入口统一 | 按域名合并导致证据丢失 |
| 来源冲突 | 地址来源不同 | 明确冲突/消歧状态 | 只选一个地址装作确定 |
| 键盘开合 | 连续至少5次、输入多行 | 单面板/单输入；内容适配、状态保留 | 新底板、抬升两次、pin重建、草稿丢失 |
| 地图卡片联动 | 点击卡片、拖地图、再选pin | 同一实体同步，镜头只按明确意图移动 | 卡片A高亮B、来源刷新抢镜头 |
| 异步过期响应 | 城市/视口快速切换 | 后到的旧请求不覆盖新活跃范围 | 新城市显示旧城计数且无范围说明 |
| 动作真实反馈 | 取消登录/分享失败/收藏失败 | 保留对象，准确显示状态 | 无执行却出现“已收藏/分享” |
