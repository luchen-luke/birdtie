# Aberdeen Closed Pilot Plan

Status: proposed pilot plan and internal targets, not evidence that the capabilities are live. Source: `Birdtie_Execution_and_CSSA_Partner_Pack.zip!/Birdtie_Execution_and_CSSA_Partner_Pack/docs/06_ABERDEEN_PILOT_PLAN.md` (imported 2026-09-30).

## 1. Objective

验证三个核心假设：

1. 学生是否真的存在“我不知道附近现在有什么”的发现问题。
2. 自然语言 + Local Pulse 是否比在多个群、网站、社交媒体之间寻找更有效。
3. CSSA/其他组织是否愿意使用 Birdtie 发布内容，因为它能增加触达并降低重复沟通成本。

## 2. Pilot Shape

优先不是“1000 downloads”，而是：

- 3-5 partner organizations
- 25-40 useful activities
- 50-100 testers（Beta 前）

第一步甚至只做：

- CSSA
- 1 real event
- 10-20 testers

## 3. Phase A - One-event CSSA Pilot

### Birdtie provides
- verified organization profile
- real event page
- Now/Local Pulse discovery
- Personal Agent discovery
- RSVP/Save
- reminder/update notifications
- basic analytics
- hands-on support

The current local preview has an in-app “帮助与举报” form and a persisted report number. Before a live CSSA pilot, assign a named Birdtie operator to review the restricted report queue, define how testers can reach that operator when the app or API is unavailable, and record response/closure handling. The present local queue is not automatic outreach or an emergency service.

### CSSA provides
- one committee contact
- logo + official intro
- event facts
- permission to display official public info
- 5-10 committee/member testers
- short feedback session

### Not requested
- member list
- private WeChat history
- access to all group chats
- payment/commission
- exclusive cooperation

## 4. Pilot Timeline

T-14 to T-7:
- verify organization profile
- create event
- committee test
- resolve P0

T-7 to T-1:
- small invited tester group
- check discovery and RSVP
- final event details

Event day:
- monitor logs
- handle urgent updates
- record RSVP / attendance signal if available

T+1 to T+3:
- committee debrief
- student interviews
- funnel review

## 5. Pilot Funnel

Track：

```text
Now/Agent impression
 -> Activity detail
 -> Save/Join
 -> Reminder delivered
 -> Event participation proxy/confirmation
```

Minimum analytics：
- views
- detail opens
- joins
- saves
- entry source

## 6. Qualitative Questions - Students

- 你原本会去哪里找这个活动？
- Birdtie 是否让你更快知道附近有什么？
- 你最信任/最不信任的信息是什么？
- Agent 的回答是否比筛选器自然？
- 哪一步差点让你放弃？
- 你会因什么原因下周再打开？

## 7. Qualitative Questions - CSSA

- 当前发活动最耗时间的步骤是什么？
- 新生重复问的问题有哪些？
- 修改地点/时间如何通知？
- 现在能否判断看到活动的人最终有没有参加？
- Birdtie 的发布流程是否比现有流程增加工作？
- 什么数据/自动化会让你愿意长期使用？

## 8. Expansion Logic

CSSA pilot 成功后：

1. Sports club
2. International society
3. Academic society
4. Interest/lifestyle society

目的不是数量，而是验证跨类型适用性。

## 9. Aberdeen Supply Opportunity

AUSA 官方信息显示其生态包含 200+ societies/student groups 与 55+ sports clubs，且官方目录中包含 Chinese Students and Scholars Association in Aberdeen。该生态为单城供给验证提供了足够多的潜在组织，而无需 MVP 阶段立即多城市扩张。
