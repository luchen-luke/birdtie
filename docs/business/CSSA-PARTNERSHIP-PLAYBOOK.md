# Birdtie x CSSA Aberdeen Partnership Playbook

Status: outreach preparation, not an agreed partnership or a claim that Pilot features are live. Source: `Birdtie_Execution_and_CSSA_Partner_Pack.zip!/Birdtie_Execution_and_CSSA_Partner_Pack/docs/07_CSSA_PARTNERSHIP_PLAYBOOK.md` (imported 2026-09-30). AUSA's public CSSA and About pages were checked on 2026-09-30; confirm the current committee and contact before outreach.

## 1. Partnership Positioning

不要以“帮我推广 App”开场。

定位：

> Birdtie 希望成为 CSSA 面向学生发布活动、降低重复答疑、帮助新生发现组织、并观察活动转化的轻量工具。

第一阶段不是商业合作，而是 **Founding Organization Pilot**。

## 2. Why CSSA Fits the Pilot

AUSA 官方页面列出的 CSSA-ABDN：
- 2017 年成立
- 面向 Aberdeen 中国学生和学者
- 持续举办社交、文化、体育等活动
- 每学期开学会组织 Welcome Event
- 通过官方 WeChat 发布活动信息
- 公开表示欢迎与其他 association 合作

这意味着 CSSA 同时有：
- 高频活动供给
- 新生信息需求
- 活动发现问题
- 组织运营场景

Source: https://www.ausa.org.uk/organisation/aucssa/

## 3. First Meeting Goal

不是签协议。

只达成三个结果：
1. CSSA 委员会愿意提供真实工作流反馈
2. 确定一个 1-event pilot
3. 确定一个委员会联系人

## 4. 20-Minute Meeting Structure

### 0-3 min - Context
- 自我介绍：Aberdeen alumni / former student
- 一句话解释 Birdtie
- 明确不是来要求立即推广

### 3-10 min - Discovery interview
问：
- 活动现在怎么发布？
- 微信/公众号/Instagram/AUSA 页面分别有什么作用？
- 新生最常问什么？
- 活动临时变更如何通知？
- 能不能知道多少人“看了但没来”？
- 换届后内容/经验是否容易丢失？

### 10-15 min - One journey demo
只演示：
`Find Chinese student events this weekend`
-> CSSA verified result
-> Activity Detail
-> Join
-> Plans

不要讲复杂 Agent Graph。

### 15-18 min - Pilot offer
提出 1-event pilot，完全免费。

### 18-20 min - Ask
只要：
- 1 contact
- 1 event
- 5-10 testers
- 15 min debrief

## 5. Founding Organization Partner Offer

Pilot period：Free。

CSSA 获得：
- Verified organization page
- Activity publishing
- Birdtie Now / Map discovery
- Personal Agent discovery
- RSVP / Save
- Participant update notifications
- Basic analytics
- Organization FAQ/Agent knowledge
- Direct product support
- Founding partner feedback priority

## 6. What Birdtie Does Not Ask For

- 不获取 CSSA 私人会员名单
- 不读取私人微信群历史
- 不要求排他
- 不要求佣金/付费
- 不要求第一天公开推广
- 不代替 AUSA/CSSA 官方渠道

Birdtie 是增量发现与参与工具，不宣称成为 CSSA 唯一官方渠道。

## 7. One-event Pilot Deliverables

### Birdtie
- profile setup
- activity setup / admin onboarding
- QA on Android/test device
- monitoring
- participant flow
- post-event analytics summary

### CSSA
- accurate event details
- official logo/description
- 1 admin contact
- invited testers
- notify Birdtie of critical event changes

## 8. Success Criteria

合作不是看下载量。

重点：
- students can discover event without already being in the right WeChat group
- detail -> join conversion
- publishing effort <= 3 min after onboarding
- CSSA committee perceives lower/neutral operational burden
- CSSA wants to run a second event

## 9. Objection Handling

### “我们已经有微信/公众号/Instagram。”
回答思路：
Birdtie 不要求替换它们。现有渠道擅长触达已经关注 CSSA 的人；Birdtie 想解决的是“还没进入正确群、还不知道关注谁”的发现阶段，并把多个公开活动放到统一地图/Agent 上。

### “我们为什么要再维护一个平台？”
回答思路：
Pilot 目标是把发布控制在 3 分钟，并可从活动文案辅助提取字段。若增加明显额外工作量，Pilot 就说明产品需要调整，不要求 CSSA 继续使用。

### “你们会拿会员数据吗？”
回答：
Pilot 不要求会员名单、群聊记录。只处理用户主动创建的 Birdtie 账户和报名行为；CSSA 只看到活动运营需要的汇总/报名状态，具体权限以产品和隐私规则为准。

### “产品现在成熟吗？”
回答思路：
明确处于 closed pilot，而不是假装成熟。正因为是 pilot，CSSA 可以影响产品设计；Birdtie 会提供直接支持，并从 1 个活动开始而不是大规模迁移。

### “如果出问题怎么办？”
回答思路：
保留 CSSA 原有渠道作为 authoritative fallback；Pilot 不要求依赖 Birdtie 作为唯一通知渠道。关键问题可立即暂停/回滚活动展示。

## 10. Partnership Stages

### Stage 1 - One-event Pilot
1 event / 5-10 testers / no promotion requirement

### Stage 2 - Founding Organization Partner
multiple events / organization admin / analytics / FAQ

### Stage 3 - Campus Ecosystem Case Study
在 CSSA 自愿同意后，用匿名/聚合结果向其他 societies 或 AUSA 展示案例。
