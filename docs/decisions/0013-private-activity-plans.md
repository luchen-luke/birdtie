# ADR 0013: My Activities 的私人计划清单

日期：2026-09-30  
状态：首批实现

## 决定

当前 Birdtie 只有 City Seed 公开 Activity，没有报名、参与确认或用户主办流程。My Activities 首批承载用户主动标记的“计划参加”清单，不把公共 Activity、Saved 书签或浏览记录称为“我已参加”。此计划仅对本人可见，不通知主办方，也不计入参加人数。用户可随时取消计划。

只有当前公开、未取消、未结束、未过期且对本人可见的 Activity 可加入计划。读取时重新检查 City/Activity 发布状态、有效期和双方屏蔽；若目标不可见，只显示不可用占位并允许移除，不返回旧标题、城市或时间。活动结束或取消后保留真实状态，方便本人回看和清理。计划与 Saved 是独立关系：收藏表示留存参考，计划表示个人意向，均不构成报名。

真实报名、主办、人数和活动协作必须由后续独立状态机与明确确认实现。此切片不复用 Civu 代码或数据。
