# ADR 0015: People 自愿公开的粗略区域标记

状态：已实现首批发布与检索，2026-09-30。

公开 Intent 仍必须由本人确认、使用公开 Profile、填写粗略区域文字并遵守有效期。Owner 可额外选择不在地图显示，或选择城市中心、北、南、东、西五个大范围之一。默认不显示。客户端不读取或上传 GPS、住址、任意经纬度；数据库只保存区域代码。仅当城市已有公开地图视图时才允许选择标记。

City Graph 查询沿用公开 Intent 的 Account、Profile、状态、时间、City 和双方 Block 检查。对选择了区域的结果，服务端根据公开城市地图视图中心生成固定示意锚点；这不是用户坐标、区域边界、实际活动地点或精确位置。地图标记和辅助说明均标为近似区域。未选择区域的真实 People 仍只在结果列表展示。撤回 Intent、变更 Profile 为私密或屏蔽后按原可见性规则停止出现。

本切片不迁移 Civu 定位数据，不保存设备位置，也不将区域代码用于推算行踪。未来如需真实街区多边形、区域编辑或更精确的聚合展示，应另建经审核的城市区域目录和隐私评估，不能把当前示意锚点当作地理事实。
