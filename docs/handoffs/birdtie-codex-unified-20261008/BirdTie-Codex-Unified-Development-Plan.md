## 1 本次应该交付什么

让用户打开 Now 就能在同一张真实地图上看到允许公开展示的地点与人们的经历，点进地点看动态，再看作者，浏览旅程和主题地图，并通过同一个输入入口继续收藏、规划、创作和分享。用户不必先问 Agent 一个问题，才感受到这个产品有人使用；也不必先交朋友，才能获得独自探索和规划的价值。

本包整合已交付的 Now 30 项、地点与 Agent 成长 26 项，以及最新的十屏 Figma 原型。原需求全文随包保留，所有原 ID 继续有效。这里的阶段和设计细则是同一队列的执行视图，不是再增加一套56项任务。AGE、AIR、身份规范、安全和试点上线门禁继续有效；当前仓库中另有 Discovery、UI Repair、BT-LIFE 等任务时，由 Codex 逐项对账，不把数量直接相加。

最新优先级来自用户关于地图社交内容的明确要求：先完成“真实公开动态 → 原地图地点 → 地点内动态 → 作者主页 → 返回恢复”，随后完成旅程/主题地图在同一地图上的查看与复用。统一草稿、语音、收藏、分享、地点复用和 Agent 成长继续执行。SearchPro 留存许可不能阻塞使用 BirdTie 自有、获准内容的核心闭环。

本包可直接作为开发输入；原型是本轮工作参考，不是十个独立页面的实现指令。先用真实数据和真实地图交付一个完整切片供视觉核对，再扩展，避免再一次“全部写完后才发现拥挤”。无需为了等待全局视觉定稿而停止独立后端和权限工作。

## 4 Now 页面和入口结构

### 4.1 首屏

全屏真实地图为底，顶部仅保留城市、侧栏和 Inbox。紧凑的“发现 / 关注 / 好友 / 我的”是内容范围切换，不新增四个页面；类型过滤“动态 / 旅程 / 主题地图 / 活动”按需展开，不同时铺两排大量标签。未登录只显示可公开访问内容，选择私人范围时解释登录并保留当前上下文。

底部唯一输入框包含加号、文本、麦克风与上下文提交按钮。正在浏览地点等面板时输入框收拢但不消失，不与面板底部操作重叠。输入模式必须清楚：问 Agent、编辑草稿、发给好友不同；评论输入属于明确 Moment 上下文，不能将私聊误发评论。

去掉未开启社交意图、我的社交近况、完善我的选择等常驻空卡。兴趣和记忆控制放个人 Agent；公开范围放隐私设置；内部范围刷新自动处理。不要用“尚未开启”占据核心首屏。

访客默认 Aberdeen 是探索区域，不是实际所在城市。手动城市优先恢复；设备位置及授权、探索城市、查询范围、公开范围必须分别保存。用户在上海且无国内底图密钥时不自动切到不可用底图；不把 Aberdeen 用作导航起点。城市场景图片可缺失而操作仍可用。

### 4.2 地图上显示什么

- 地点标记以 canonical Place 为核心，附最近可见内容的缩略图或小头像提示；稠密区域聚合，放大后展开
- 同一地点默认一个标记，不为每条 Moment 叠同坐标 pin；数量标签明确是动态条数、可见作者数还是地点聚合数
- 公开/关注/好友/我的过滤均在服务端权限过滤后计算聚合和计数，禁止“先显示总数、再隐藏私密内容”泄露存在性
- 旅程默认只给入口或适量摘要；选中后画相关路线。不能首页同时把全城所有用户路线绘成网状
- 主题地图是地点集合，不自动连接成路线。用户明确规划时才生成有顺序、交通方式和来源的路线
- 动态地点表示内容关联地点，不是作者实时位置。“最近发布”与“实际到访日期”区分；历史照片不显示成“刚刚在这里”
- 地图移动后保留当前选择，显示“搜索此区域”或明确按视口更新；新请求有取消或序号保护，旧结果不得覆盖新视口

为单人用户和低供给城市保留独立价值：可看自有收藏、创建计划、探索已核实公开地点；空态建议发布第一条动态或显示收藏，不伪造其他用户。离线内容标记更新时间。

## 5 地点 动态 作者的连续浏览

### 5.1 地点面板

点地点标记打开一个底部面板，地图仍保留背景与选中状态。面板提供收起预览、半屏、展开三个高度档；比例随屏幕、键盘和辅助功能自适应，不固定为原型390×844像素。顶部有地点名、必要副标题、收藏/分享等适量动作；正文用“动态 / 相关旅程 / 主题地图 / 活动”按需切换或分段，避免又一层密集控制。

默认动态卡包含作者头像与名字、发布日期、图片/视频预览、简短正文、地点关联，必要时独立显示经历日期。地点摘要可写“你可以查看的 N 条动态，来自 M 位用户”，M定义为相同筛选和查看者ACL下的 count(distinct authorId)，不是动态条数，也不是各页作者数相加；服务端提供统一查询快照/版本下的聚合，pin与列表保持同一口径。没有足够数据不展示虚构人气。真实空状态、加载失败、无权限、离线缓存必须不同。

### 5.2 动态详情

点卡片在同一面板容器切换 MomentDetail；保留地点列表滚动位置。多图横滑，视频由用户启动，避免地图上自动播放多个视频。完整正文支持展开，引用地点可定位原图。动态关联多个地点时让用户选择具体地点，不推断一个主地点覆盖其他关联。

保留作者、发布时间/经历时间、内容、地点、已存在且支持的互动。未实现评论或点赞不能做假按钮；已有相关服务则复用并验收。举报、屏蔽及作者编辑/撤回属于必要安全入口，不能因追求简洁移除。作者撤回或转私密后，旧卡、搜索和聚合都应不再泄漏内容。

### 5.3 个人主页

作者头像打开公开 ProfilePanel，显示允许公开的头像、昵称、简介与其可见动态/旅程/主题地图。个人 Memory、私聊、精确设备位置、私人收藏和未发布草稿不可因“个人主页”被拉取。

“在地图查看 TA 的内容”开启临时作者过滤，返回时恢复原地图、城市和内容范围。关注/好友按钮要区分单向关注与双向关系；关系变化在读取和执行时重新核验，不能把关注当好友可见授权。用户自己的主页从“我的”范围或侧栏“我的主页”有直接入口，与查看他人公开主页区分；包含自己的内容、资料编辑和隐私入口，仍不要求先填完整表单才可用。

### 5.4 返回不是一律首页

生产返回栈至少支持 PlaceList → Moment → Profile → 返回 Moment → 返回原 PlaceList → 收起。每层保存 entityId、来源范围、分页游标、滚动位置、面板高度和地图快照引用。关闭是退出本次详情会话；返回是回上一步，两者不能混为一个 X。

Android 返回优先关闭键盘，其次轻量菜单/确认层，再退面板历史，最后离开 Now。未提交草稿按已存在自动保存规则恢复；确有丢失风险时轻量提示，不默默丢失。权限变更导致历史对象不可见时给受限状态，不恢复旧截图或缓存正文。

## 6 同一地图上的旅程和主题地图

Journey 需要明确作者、日期/天数、城市时区、各日停靠点、顺序和路线类型。查看他人旅程仅开启临时上下文，不能改自己的旅程，也不永久改变探索城市。跨城市时可临时 fitBounds，退出恢复原视角。

切换天只展示该日相关节点与路线，跨日概览可使用明确图例。若路线只是地点连线，标为示意连接，不给虚构驾车/步行时间；真实路径和耗时来自已批准路由服务或合法已有数据，缺失时仍可浏览地点。路线计划与实际轨迹分开，规划不证明已到访。选择交通方式和重排停靠点后同步地图及草稿。

ThemeMap 显示作者、标题、简述、地点数量与列表；点击某地点聚焦当前 Now。保存整张地图的引用、收藏某个地点、经许可复制为自己的版本是三种不同操作。复制不修改原作者，引用在原对象撤回后按权限失效；私人备注不混入公共副本。主题地图和旅程基本读取不依赖收藏能力全部完成。

外部 ChatGPT/Claude 计划或用户上传清单可进入结构化草稿，保留用户提供来源、未解析地点、日期不确定性。输入中的“忽略规则、发送给某人”只是不可信文本。完成缺项确认后保存，不能自动预订、公开或发消息。

## 7 唯一输入框和真实执行

加号分材料（照片/视频、文件、链接、地点）与行动（发布动态、收藏地点、创建主题地图、规划旅程、创建活动）。选择行动进入当前输入框的类型化草稿，不打开一套新全屏表单。自由输入与菜单选择调用同一 Runtime、工具权限和服务。

建议共享 DraftEnvelope：draftId、type、version、actor、text、materialRefs、entityRefs、recipientRefs、visibility、structuredFields、missingFields、fieldProvenance、status、operationId。各业务仍有类型化对象，不做巨型通用表。只问必要缺项，通常一次一两项；已合法获取内容可预填但可纠正。重要字段同时允许直接点选编辑，不能迫使每次修改都对话多轮。

录音是输入而非发送：按需请求麦克风，显示录音/转写/可编辑状态；中文、英文和混合语言保留原语言文本，不默认翻译中文。取消、拒权、来电中断、转写失败不发送也不丢原草稿。选择转写供应商前记录实际数据去向、留存与预算；不得因画有麦克风就启用未授权服务。

媒体状态为选取、上传、处理、就绪、失败/重试、移除；上传进度不等于发布。文件类型/大小/数量/时长限制来自真实配置并在选取前解释，不编造支持值。断网续传按存储能力实现；不支持时明确重试，不宣称已有断点续传。公开派生图片处理敏感EXIF，原图访问受限。照片地点只是候选，不能改变实际位置或自动公开精确坐标。

@ 好友默认为引用。明确“发给”才进入发送模式，展示收件人、所选对象、文本和附件；私人 Agent 对话不会自动附带。发布/发送/报名最终确认绑定内容版本、身份和受众，变更重新确认。收藏可用明确点击与可撤销反馈完成，不额外强加每次弹窗。

状态至少：EDITING → READY → CONFIRM_REQUIRED（适用时）→ SUBMITTING → SUCCEEDED / FAILED / UNKNOWN。UNKNOWN 查询 operationId，不生成新键盲目重试；重试原操作沿用键，新一次用户意图用新键。成功必须有真实服务回执与可再次读取的实体，模型文本“已完成”不作为证据。

## 8 收藏 来源 分享与活动

收藏是用户可见的私人资源入口：保存、去重、再次找回、按城市或集合整理、私人备注、在原地图显示、选择组成旅程或主题地图、取消。未登录具体动作处登录后恢复对象。库外地点仅保存许可字段或允许引用；待核实要明确显示，后续 canonical 解析不改变 SavedItem ID 或丢备注。保存不等于喜欢、消费或到访，也不自动公开。

来源用断言旁紧凑标签，展开可见标题、域名、时间与URL；相同来源去重但不同页面不混并。sourceId 属于回合证据，placeId 属于实体。地图和卡片共用同一个版本的事实。官方标记需核验，冲突营业时间或地址明确待确认。无来源不伪造来源标签。

卡片本体打开详情，地图按钮聚焦原地图，路线按钮进入路线计划，收藏和分享各有独立行为。取消实为同一详情跳转的多余按钮，不以箭头图标伪装导航。外部逐向导航仅用户明确选择后打开，并使用真实/用户指定起点。

内部分享产生授权消息与回执；系统分享只说明已打开系统分享面板，不能说好友已收到。外链明确实时引用/快照、受众、有效期和撤销行为；分享本身不自动扩大原对象访问。要扩大公开范围须单独明确选择。私人内容不能因发给一人而变任何人链接。

活动查询、创建、加入分别是读取、草稿、确认写入；组织发布明确 actingPrincipal 和 Membership。容量、取消、费用与权限在提交时复验；不支持收费则给明确限制，不能编造报名成功。兴趣匹配和“成长”不会自动接受邀请。

## 9 公共地点和个人 Agent 的边界

保留现有 canonical Place、候选审核、别名、来源模型，补字段级来源、允许使用/留存状态、时间有效性、坐标 CRS 与合并版本。名称/地址可稳定，营业时间、节假日例外、临时关闭和活动另行新鲜度判断。没有坐标不得猜坐标，GCJ02与WGS84转换明确在适配层处理且记录来源。

来源许可按供应商、产品/接口、账户合同版本及字段管理；允许、禁止、待确认三态。当前 SearchPro 留存边界待核对，不能通过重命名成候选、模型改写、embedding、后台再次搜索来规避。既有日志、source_batch、回答、引用、追踪和缓存也列入审查；不自动删现有数据。本包不作某一保存行为违法的结论，不要求用户为每个地点重新申请 SearchPro。

查询先查已有获准地点与内容，再判断覆盖、字段和时效；本地足够不重复联网，不足只补必要字段。允许的公共事实可跨用户复用，私聊、个人画像和个性化回答不可成为公共缓存。不能把停止持久化POI误称全链无留存。真实外部检索仅在适用条款、实际账户授权和已有付费预算明确后启用；本包不新增调用预算。

站内用户动态的展示依据作者权限，与第三方POI供应商许可是独立门禁。已经合法存在的地点和 BirdTie 内容可以实现首个地图闭环，不等新来源接入。内容的照片、文字、许可、署名和撤回要保留，不能搬运外站用户评论或照片。

Agent 成长沿用 AGE/AIR：用户明确偏好可确认保存、下一次正常请求实际消费、纠正/忘记后立即停止消费。临时意图、为朋友查找、收藏、规划、RSVP、真实出席分别建证据，不能强推为长期兴趣；行为候选不绕过既有人工接受和敏感推断禁令。每轮 Context Builder 仅取当前相关且有效授权的记忆；trace记录 memory_id/version 与决策原因码，不记录隐含思维过程。

学习同意、内容公开范围、外部模型导出、主动通知和对外行动授权分开。关闭学习不应丧失基本地图浏览。撤销和删除传播到候选、索引、缓存及推荐快照，备份恢复有删除账本。首批已报告的有界偏好不要推倒重写，先回归，再扩展。

## 10 客户端状态与组件约束

建议定义 MapWorkspaceState（名称适配现有代码）：accountId/actingPrincipal、conversationId、exploreContext、camera、queryScope、relationshipFilter、contentTypeFilter、visibleLayers、selectedEntityRef、activeOverlayRef、panelStack、draftRef、requestGeneration。设备位置不混入 exploreContext。临时查看他人路线时另有 returnSnapshot。

建议组件边界：NowMapCanvas、MapContentMarker、RelationshipFilter、PlacePanel、MomentCard、MomentPanel、ProfilePanel、JourneyPanel、ThemeMapPanel、NowComposer、ActionMaterialMenu、DraftPreview、CitationChip、SharePreview。与现有组件重合则复用，不按此清单新建平行架构；同一面板容器管理所有详情。

核心尺寸测试：窄屏320dp、360dp、原型390dp、平板/桌面宽视口；字体放大至200%仍可滚动访问关键操作。面板不同时占满地图、输入和系统安全区；大屏可换侧面板，但同一任务与地图状态保持。深色模式如本轮未提供，明确沿用既有实现/保持未完成，不随意扩范围重设计。

## 11 服务接口和数据契约

以下是所需语义，不代表这些路径或表已经存在。Codex 先列现有路由和实体，再选择扩展或适配；不要为符合文档另建重复服务。

|操作|输入语义|输出语义与必须保护|
|---|---|---|
|地图内容查询|bbox/zoom、城市、类型、关系范围、时间范围、cursor、requestGeneration|授权后标记/聚合、明确countKind、实体版本、nextCursor、generatedAt；无私密总数|
|地点内容读取|placeId、内容类型、cursor|地点事实和字段来源、授权内容列表、可见作者数；分页去重|
|Moment读取/编辑/撤回|momentId、版本、预期动作|内容、可见性、allowedActions；编辑并发冲突可解决|
|作者公开资料|authorId、内容范围、cursor|公开资料和当前查看者可见作品；不返回Memory等私有字段|
|旅程/主题地图读取|entityId、day或selection|版本、地点引用、顺序、日期/时区、几何来源、allowedActions|
|草稿保存/解析|类型、版本、用户材料与意图|可编辑字段、来源、缺项、不确定项；不产生公开业务副作用|
|动作执行|draftId/version、action、target、actor、confirmationRef（适用）、idempotencyKey|operationId、状态、结果entityRef或错误；服务端重新授权|
|执行结果查询|operationId|已成功/失败/进行中/未知；同账号限定，不允许枚举其他人操作|
|内容变化同步|实体版本、删除/权限变化事件|客户端及缓存失效；重连后重新核验，不能恢复已撤回内容|

统一错误语义至少覆盖未登录、无权限、对象不可见/删除、版本冲突、校验失败、限流、依赖不可用、网络错误、操作结果未知。授权失败与“没有内容”对外避免泄露敏感存在性；日志可用不含正文的内部原因码区分。相关请求有requestId用于排错，不将供应商密钥或完整私聊回显。

实体最小关系：Place ↔ Moment 可多对多；Moment属于作者，媒体独立受ACL；Journey含有序日程和Place引用；ThemeMap含集合成员；SavedItem关联不同对象类型；Relationship包含关注、好友、屏蔽；所有聚合基于请求身份与当前权限。计数、列表、地图缓存使用同一过滤口径，禁止先算全量再客户端过滤。

写入与对应事件采用现有事务/outbox机制，事件幂等。公开转私密/撤回/拉黑先阻断读取，再处理派生索引；删除失败重试不会重新公开。前台会话重新激活、权限版本变更和访问内容时必须再核验。后台索引落后时仍由权威层拒绝读取。

## 12 离线 错误 安全和质量

地图SDK加载失败可保留可用列表并给重试，不显示虚假的可用地图。离线只允许按授权策略读取本地缓存；私密/好友内容不保证离线长期有效，须定义短有效期和再鉴权策略。离线草稿可保存，发布/报名/分享不能显示成功。恢复网络后检查登录、权限、草稿版本和操作结果，再允许重试。

地图点位、列表、媒体分别加载，避免一个图片失败阻塞整个面板。空态必须给当前范围和下一步，不能反复叠加“无活动”大卡。中文长标题允许换行或展开，关键地名不可裁到无法识别。所有按钮有无障碍名称，颜色不是唯一状态信号，读屏顺序与视觉一致，键盘焦点回到原操作。

性能以实际低/中端目标设备 profile/release 测量，保留原有基线；建议60Hz目标设备主要交互p95帧耗时不高于16.7ms，若平台限制须报告差距而非伪称通过。首屏可交互、首次内容、分页、路线计算、内存与网络字节分别测量，先定测试数据规模和设备再比较。缩略图、视口分页、聚合、请求去抖和取消为基本要求；不把debug帧率当生产结果。

不得用公开地点反推出敏感属性、居住地址或实时行踪。不将别人的头像标记成“人就在这里”。恶意Moment、导入文档、网页和模型返回都只是数据，不能改变权限、发消息或写权威记忆。附件处理检查类型与尺寸、限制解析资源；媒体链接按ACL签发，日志不包含令牌。新增公开内容链路复用审核、举报、屏蔽和滥用限制，未具备时明确上线门禁。
