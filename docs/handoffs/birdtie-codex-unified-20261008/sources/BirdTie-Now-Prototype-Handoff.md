## 本稿的明确边界

- 10 个 390×844 画板，259 个原生可编辑文字层、40 个组件实例；颜色/间距/圆角 token 可修改
- 所有人名、动态、计数、路线和内容均为演示数据；地图几何仅说明交互，不代表真实 Aberdeen 道路或坐标
- 插画为可编辑原生矢量占位内容，不是商户实拍。真实图片上传接口此次不可用，未使用空图片冒充完成
- 五张历史截图本次无法重新取回；本稿依据用户逐项描述及此前记录的问题，不宣称已完成逐像素复刻
- Noto Sans SC 为本稿中文字体建议，非已核验生产字体
- 语音录入、文件上传、发送、发布、收藏持久化、城市切换、侧栏、Inbox 尚未做成真实功能；其入口或确认方式仅作展示。未接入联网搜索和任何付费服务
- 返回目前回首页，不是完整生产历史栈；系统分享、评论、动态权限变化等需后续状态设计与真实验收

## 给 Codex 的落实规则

请先读取现有需求和当前任务记录，在自然检查点对照这份 Figma 原型，不打断调试，不另建重复队列，不覆盖未提交修改。先确认视觉方案，再按模块实施。

1. 保留一个 Now 地图实例。地点、Moment、作者、Journey、ThemeMap 用可恢复的面板状态与地图覆盖层切换
2. 地点聚合仅统计当前用户有权查看的内容与作者；任何动态标记都不等于用户实时位置
3. 默认 Aberdeen 只表示探索区域，不能假冒设备定位；后续定位授权/拒绝状态独立处理
4. 公开地图浏览与私人 Agent 对话分离。收藏、分享、发布明确对象、范围和结果；不得把私人对话附带给好友
5. 统一输入框承接自然语言、＋材料/行动、语音转写。转写先填入可编辑草稿，不自动发送；中文/英语/混合输入分别验收
6. 紧凑来源仍须映射到真实可打开 URL 和对应事实；不得将动态来源、地点来源、模型推断混写
7. 实现时必须补齐小屏、大字体、键盘、安全区、加载/空/错、回退保留状态、权限变更、弱网与重试验收
8. 图中发送/发布/录音只是原型，不能据图把功能标 DONE。真实接口、权限、持久化、结果回执和失败恢复都须单独证明

建议先评审首页密度、地点→动态→作者链路及路线复用，再做语音和完整草稿；以用户最终确认的顺序为准。
