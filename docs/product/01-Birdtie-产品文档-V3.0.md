## 1. 产品定义

Birdtie 是连接**人、城市与现实生活**的社交发现平台。它让用户探索一个城市现在和过去发生过什么，从内容中形成兴趣与 Intent，找到合适的人、组织、地点或活动，在双方同意下采取真实行动，再将新的经历沉淀为 Moment、Experience 或 Journey，继续丰富个人与城市。

### 完整闭环

**Discovery → Desire → Intent → Connection → Activity → Experience / Moment / Journey → Discovery**

- **Discovery：** 用户发现城市、地点、人物、活动、社区或历史内容。
- **Desire：** 内容激发兴趣，“我也想去/体验/认识”。
- **Intent：** 将模糊兴趣转成可行动的主题、时间、地点范围、参与条件与有效期。
- **Connection：** 用户与用户、组织、社区或活动建立经双方认可的联系。
- **Activity：** 进行活动、会面、旅行或其他现实行动。
- **Experience / Moment / Journey：** 用户选择记录和整理经历，供个人留存或公开分享。
- **Discovery：** 新内容回到地图、城市页、个人页、社区与搜索，激发下一轮发现。

Birdtie 不以无限 Feed 消费为目标。内容首先帮助用户理解“这里有什么、谁在做、我可以参与什么”，并让兴趣有通往行动的路径。AI 帮助理解、整理和匹配；用户始终掌握公开、联系、报名和承诺的决定权。

## 2. 核心原则

1. **Every experience can enrich both a person and a place.** 用户确认公开的一份经历，可以同时成为个人故事、地点记忆、城市内容和社区历史。
2. **Memory ≠ Moment。** 私人原始素材不会因为上传或被 Agent 读取就自动公开。Memory 是私有输入；Moment、Journey、Experience 是经用户审阅确认后产生的内容对象。
3. **One object, multiple contexts.** 同一个 Moment/Journey/Activity 只保存一份权威对象，通过关系链接出现在 User、Place、City、Community、地图、搜索等上下文，不复制出多份内容。
4. **Agent assists; people decide.** Personal Agent 可以归类、建议地点、拟标题和生成发布草稿，但对外发布、标记他人、建立关系、报名或承诺必须由有权限的人确认。
5. **过去内容有未来用途。** 已结束的活动和历史 Journey 清楚显示时间与结束状态；它们仍可帮助用户收藏、复刻路线、关注类似活动或创建新 Intent。
6. **隐私与可发现性可分层控制。** 对象作者、合作者、受众、地点精度、时间精度和用途分别管理；精确位置、私人原图和他人身份默认受保护。
7. **关系需要同意。** 看过同一内容、出现在同一地点或参加同一活动，不会自动成为好友或会话成员。
8. **城市 Agent 有据可依。** 城市问答和建议基于可见的地点、活动、Journey、Moment、Community 与组织资料，并说明来源与更新时间。
9. **地图和列表并重。** 定位是可选项；Explore Anywhere 可以在用户不在当地时浏览任何城市。

## 3. 用户与核心需求

| 用户 | 主要任务 | Birdtie 提供的价值 |
|---|---|---|
| 新来城市的学生/迁居者 | 快速了解城市、找到活动和同行者 | 城市生活层、可信组织、可行动 Intent、低压力联系 |
| 本地居民与兴趣社群成员 | 找同好、组织活动、分享经历 | 兴趣/地点发现、社区空间、活动与 Moment 关联 |
| 往届学生与 Alumni | 保存城市经历、帮助后来者 | 历史内容整理、城市贡献者身份、经验持续可用 |
| 计划来访者/远程探索者 | 在出发前研究城市与路线 | Explore Anywhere、历史 Journey、活动与地点记忆 |
| 学联、学校社团、社区组织 | 发布活动、维护资料、持续服务不同届成员 | 组织主页、City Seed 内容、活动管理、City Agent 知识来源 |
| 场馆与本地商家（后续） | 被合适的人发现、承接到访 | 地点与活动关系、透明的商业信息与转化入口 |

首发可从 Aberdeen 华人人留学生、学联和往届学生切入。这是试点方向，不表示合作已签订或供给已确认。

## 4. 产品结构与信息架构

```text
Birdtie
├─ Now / Today：本城或选定城市正在发生什么
├─ Explore：Explore Anywhere；城市、地图、地点、Moment、Activity、Journey、Community
├─ Network：People、Intent、Connection、Community
├─ Inbox：联系请求、真人会话、Agent 接待、组织人工接管
├─ My Birdtie：个人主页、Memory 私库、公开 Moments/Journeys、收藏、Intent
├─ Personal Agent：私人素材整理、个人偏好、授权、建议与运行记录
└─ Organization / City workspace：组织内容、City Seed、活动、City Agent 知识与审核
```

首页提供 Now、Explore、Network 与 Inbox 的清晰入口。地图和列表共享筛选、对象卡片和返回位置。自然语言输入可作为创建 Intent、搜索或整理素材的快捷入口；重要业务对象仍提供可编辑表单和明确预览。

## 5. 城市生活层：City Living Layer

每座城市有自己的可浏览生活层，不只是 POI 集合，也不是用户帖子时间线。它把城市的空间锚点、当下行动和历史记忆组织在一起。

### 城市页模块

- **Today / Now：** 当前与近期活动、近期公开 Moment、活跃 Intent、临时组局；显示时间、时区、状态与来源。
- **Things to Do：** 可做的活动主题，如徒步、羽毛球、摄影、海边散步、博物馆、咖啡与周末短途。
- **Places：** 地点信息、类别、开放信息来源、相关 Moments、Activities、Journeys 和组织。
- **Moments & Experiences：** 经本人确认公开的真实生活记录，可按地点、主题、时间和来源浏览。
- **Activities：** 即将举行、进行中、已结束的活动；过去活动清楚标注 Past，不显示报名按钮。
- **Journeys：** 可浏览路线、站点、时间安排和用户经验；可保存、复刻或询问 Agent。
- **Communities & Organizations：** 城市中的兴趣社区、学校组织和官方/维护资料。
- **People & Alumni：** 仅展示主动公开相关经历或贡献身份的人；不生成隐性成员名单。

### City Living 页面体验

访客可以选城市后直接浏览，不必授权当前定位。城市页提供地图/列表切换、时间筛选、主题筛选、内容类型图层和来源说明。空白城市显示平台/组织维护的基础内容和“内容正在建立”的真实状态，不伪造活跃度。

## 6. City Seed Layer 与内容供给

新城市启动时，平台先建立可信、可用的城市骨架，再邀请组织和个人补充生活细节。

### 三层供给

1. **Platform / Organization Layer：** Places、城市介绍、Things to Do、Starter Journeys、Recurring Activities、Community、官方活动与基本服务信息。资料必须有维护者、来源、更新时间和适用期限。
2. **Community Layer：** 学联、学校社团、兴趣组织与活动主办方发布活动、公告、组织 Journey、活动 Moment 和经授权的经验内容。
3. **User Layer：** 用户发布 Intent、Moment、Experience、Journey、地点建议和活动回顾；每项都尊重作者确认和受众设置。

City Seed Layer 是内容起点，不是平台虚构的用户热度。官方来源与用户经历视觉区分；过期信息降级并提示复核。组织内容可由轮值成员维护，毕业/换届时支持交接。

## 7. 内容与业务对象

| 对象 | 定义 | 关键规则 |
|---|---|---|
| Memory | 私人原始素材，如相册、旧动态导出、笔记、私人照片或文本 | 默认仅所有者可见；不进入城市公共搜索/地图/City Agent |
| Moment | 某个时间段发生的一段生活内容，可含图片、文本、地点、主题 | 发布前作者确认；一个对象可链接 User/Place/City/Community/Activity/Journey |
| Experience | 用户确认的经历或建议，强调可复用的个人经验 | 与 Moment 可分开，也可从 Moment 中提炼；来源和时间保留 |
| Journey | 一段路线或多站点旅程，可关联 Moments、Places、Activities | 每站点精度和共享范围可控；可保存/复刻，复刻创建新对象并保留来源 |
| Activity | 可参加、曾举行或周期性发生的活动 | 有明确状态、时间、主办方和报名规则；Past 不可误报可参与 |
| Place | 地理地点及其公共或用户补充资料 | 地点实体可复用；贡献和用户评论有来源及可见性 |
| Intent | 用户/组织希望进行某事的可行动表达 | 主题、时间窗口、粗区域、人数、受众、有效期；过期即退出发现 |
| Community | 围绕学校、城市或共同兴趣的持续空间 | 成员关系显式加入；内容是否公开由各对象独立决定 |
| City | 城市级内容与索引容器 | 聚合关联对象；不复制 Moments/Journeys/Activities |
| Connection | 用户或组织之间经同意建立的关系/会话范围 | 活动共同参与或内容互动不自动创建关系 |

### One object, multiple contexts

```text
Moment: “Aberdeen Beach 夏日傍晚”
├─ authored_by → User
├─ occurred_at → 2024-06 (时间精度由作者选择)
├─ happened_at → Aberdeen Beach (可降精度/隐藏)
├─ belongs_to_city → Aberdeen
├─ related_to → Community / Activity / Journey (可选)
└─ visibility → 作者确认的受众
```

个人页把它呈现为个人经历；地点页呈现为地点记忆；城市页呈现为城市故事；Journey 页显示为旅程片段。它们都读取同一个 Moment ID。移除城市关联不会删除个人对象；删除对象则更新所有投影与索引。

## 8. 历史 Memory 整理与导入

用户可选择历史相册、设备文件、用户自行导出的内容或手动上传的素材，委托 Personal Agent 整理。外部社交平台只有在存在合法且可用的授权导出/接口时才接入；Birdtie 不假设可直接读取微信朋友圈或小红书账号。

### 整理流程

1. 用户选择素材范围、来源与用途；导入进入私人 Memory 区。
2. 系统在授权范围内提取时间、EXIF 坐标、文字和媒体属性；坐标可能缺失或错误，结果标明置信度。
3. Personal Agent 建议分组为 Moments/Journeys，匹配可能地点、城市和主题，并提示重复项、他人照片和敏感内容。
4. 用户查看每个草案：内容、日期、地点/坐标精度、被提及人物、受众、是否进入个人页、地图、城市页或社区。
5. 用户编辑、合并、拆分、忽略或删除建议；只有点击确认发布后，才生成公开业务对象和索引关系。
6. 用户可撤回公开关联、改受众、删除对象及相关派生数据；原始 Memory 是否保留由用户单独控制。

Agent 是整理器，不是自动发布器。它不得从照片推断并公开敏感特征；不得默认识别人脸、标记他人或推断某人参加活动。原始素材与公开对象分层存储并分别授权。

## 9. 地图、地点与 Explore Anywhere

地图提供四类主图层：**Places、Moments、Activities、Journeys**。People/Intent 可作为受限可选图层，只显示主动公开且经过粗化的位置。City/Community 页面可聚合这些对象。

- 城市级缩放：展示城市摘要和计数，如活跃地点、公开 Moment、近期活动和 Journey 数；计数依权限过滤。
- 区域级缩放：用 Cluster 聚合对象，避免照片 Pin 铺满地图。
- 地点级：打开 Place 页面，按时间和类型浏览相关对象。
- Moment：只使用作者允许的地点精度；EXIF 精确坐标默认不直接公开。
- Journey：地图展示经作者确认的路线段/站点；可以隐藏起终点或模糊住宅附近位置。
- Activity：过去活动置于历史筛选，标注 Past；近期/当前活动提供主办方和参与入口。
- 无定位模式：用户搜索城市、点选城市或输入地址范围即可探索。

**Explore Anywhere** 支持“人在上海看 Aberdeen”“在伦敦计划 Edinburgh 周末”这类跨城探索。用户可保存地点、收藏 Journey、关注主题、向 City Agent 提问，并在感兴趣后创建 Intent 或提醒。城市切换不改变用户当前地理隐私设置。

## 10. Personal Agent 与 City Agent

### Personal Agent

理解用户显式提供的兴趣、目标和个人授权资料；帮助创建 Intent、整理私有 Memory、从公开内容生成计划、找到相关人/活动。私人上下文与对外接待知识分开。对外发布、创建联系请求、报名和承诺前提供对象、文本、范围与来源预览，等待本人确认。

### City Agent

以城市为入口，回答“这个周末有什么适合我”“以前的学生常去哪徒步”“这个地点过去发生过什么”等问题。它只使用访问者当前有权看到的 City Graph 对象、经审核的组织知识和用户公开内容。答案引用 Place、Moment、Activity、Journey 或组织资料，并标明时间与来源。资料稀少、过期或冲突时说明不确定并引导查看来源/联系组织。

### 两 Agent 协作

用户可问“结合我保存的兴趣，Aberdeen 有什么适合我”。Personal Agent 可提供最少化的兴趣查询条件给 City Agent 检索；不会把私人 Memory、完整偏好档案或身份资料写入城市公共知识。Agent 生成的解释不改变权限判断。

## 11. 从历史内容到新行动：Future Utility

过去 Activity 与 Journey 保留历史价值，同时成为未来行动的起点：

- Past Activity → 关注类似活动 / 提醒有新场次时通知 / 形成新 Intent。
- Past Journey → 保存 / 查看站点 / 复刻路线 / 询问 Agent 规划不同日期版本 / 找近期同行者。
- Moment 或 Experience → 收藏地点 / 了解社区 / 联系作者（仍需对方接受）/ 发起相关 Intent。

复刻不是篡改历史对象，而是创建新 Intent/Journey，并可选保留“灵感来源”链接。用户能看到原内容日期、组织状态和当前信息是否已复核。

## 12. 关键用户旅程

### A. 新用户发现并参加活动

选城市或允许粗略定位 → Explore/Now 浏览城市内容 → 看见活动或 Journey → 产生 Desire → 创建限时 Intent 或直接查看报名条件 → 向同行者/组织发联系请求 → 对方接受 → 报名/参加 → 用户选择是否整理为 Moment。

### B. Alumni 回填历史生活

Alumni Contributor 邀请 → 选择相册/导出材料 → 私人 Memory 导入 → Personal Agent 分组与地点建议 → 人工检查日期/坐标/权利/受众 → 确认一组 Moments 或 Journey → 内容进入个人页及选定城市/地点上下文 → 新用户发现、收藏或创建新 Intent。

### C. 组织建立 City Seed

组织核验/角色设置 → 导入地点、活动、Starter Journey 与 FAQ → 指定来源/负责人/有效期 → 发布后进入组织页和城市层 → City Agent 引用 → 组织可更新、过期、撤下或交接。

### D. 历史活动激发未来 Intent

Explore Anywhere 看到 Past Activity → 阅读活动时间与回顾 → 选择“关注类似活动”或“我也想参加” → 创建新 Intent/通知偏好 → 新活动匹配时返回 Discovery。

## 13. 联系、社区与权限体验

个人和组织都由真实 Account 承担责任。Agent 身份必须关联真实 owner，并清楚标记 AI/真人发言。

- **本人接待：** 用户发送联系请求，接收方决定是否开启会话。
- **AI 先接待：** 仅使用主人授权且当前有效的对外资料；问题超出资料时转人工。
- **访客选择：** 用户可选问 Agent 或联系本人/组织。
- **未设置：** 禁止 Agent 自动对外回复，使用普通联系请求。

联系请求可接受、拒绝、暂缓、撤回、过期、屏蔽或举报。拒绝不会触发 Agent 继续说服。连接范围说明是仅会话、活动协作还是关注；加入 Community、报名 Activity、公开 Moment 是彼此独立的动作。

## 14. 内容信任、安全与治理

- 显示对象作者、来源、发生时间、更新时间、是否为历史内容及地点精度。
- 组织资料支持核验级别、有效期和维护责任人；过期信息不作为确定答案。
- 媒体导入提示版权/共同创作者/照片中其他人的隐私责任；支持移除与申诉。
- 城市贡献者身份代表贡献记录，不代表官方认证或内容绝对正确。
- 举报、屏蔽、删除、撤权和更正入口靠近对象；限制滥用和批量导入。
- 不展示未经同意的精确个人轨迹，不把“曾在 Aberdeen”自动变成公开成员目录。
- 搜索/推荐仅检索可见对象；付费内容（如后续引入）清晰标注。

## 15. MVP 与路线

### MVP：单城生活与连接闭环

- 选城市/Explore Anywhere 基础浏览；Places、City Seed、组织主页和近期 Activities。
- 用户 Intent、发现、Connection Request、双向同意和真人会话。
- Moment 基础发布及 User/Place/City 多关系；地图/列表和地点聚合。
- Personal Agent 对用户手选文件做私有整理草稿；确认后发布；完整撤回/删除路径。
- 组织内容来源/有效期、City Agent 基于已授权内容检索和引用。
- 举报、屏蔽、速率限制、授权/审计、人工接管。

### 后续阶段

- Journey 多站点编辑、复刻、活动回顾和 Alumni 贡献项目。
- 社区共同策展、更多城市、组织轮替与城市内容质量工具。
- 语义检索、个性化排序、活动提醒和受限双边协调。
- 商业组织工具与商家服务，达到本地密度后再试。

### 核心体验验收

1. 用户能区分私有 Memory 与公开 Moment，发布前看清内容、受众、时间、地点精度。
2. Agent 不能未确认公开内容或建立连接；撤权后新访问立即被阻断。
3. 同一 Moment 在个人、地点、城市页呈现一致对象，不产生副本。
4. 过去活动明显标记为已结束；历史 Journey 能触发收藏、复刻或 Intent。
5. 地图不会因内容量增加而满屏 Pin；无定位用户仍可完整探索。
6. City Agent 的建议有可点击来源；无来源时明确表示资料不足。

## 16. 指标

北极星候选：**每周由发现转化而成的有效现实行动数**，包括双方同意的连接、确认的活动参与或用户明确完成的计划；和负面安全指标同时评估。

辅助指标：Discovery→Desire（收藏/关注类似内容/“我也想做”）；Desire→Intent 转化；Intent→Connection 接受率；Connection→Activity 参与率；Activity→Moment 自愿记录率；城市内容覆盖和时效；地点关联率；历史 Journey 被保存/复刻/产生 Intent 的比例；Personal Agent 建议确认率与撤销率；城市内容举报/更正/过期率；隐私投诉、屏蔽和撤权处理时效。

所有目标值在试点建立基线后确定，不从设计阶段推断。

## 17. 开放事项

- 既有 Civu 页面、表、API、地图能力和生产开关需重新盘点。
- 外部平台历史内容导入只在用户自行提供内容或合法授权渠道可用时建设。
- 试点组织、Alumni 邀请责任人与内容授权流程需落实。
- 地图供应商、媒体处理地区、模型服务和数据保留依据实际合同确认。
- 需要用试点确认用户是否愿意整理旧内容、何种公开默认最易理解，以及城市内容维护成本。
