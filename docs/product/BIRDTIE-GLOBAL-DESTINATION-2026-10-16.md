# Now 全球目的地与地图恢复

本文件是现有 Now 的增量规范，实施状态以原队列 DGS 检查点及验收报告为准。Android 优先，网页按用户要求延期。正常字号，不录屏。

## 浏览与发布

浏览目的地是本次地图的地理目标，不等同于本人所在地、城市社交身份或动态的公开位置。选择目的地不得更新个人资料、给草稿添加地点、清除正文或创建 POI。未登记内部城市、当地没有社区内容，都不妨碍搜索和移动地图。

Now 目的地入口使用“选择城市或目的地”“搜索城市、地区或目的地”。候选显示国家和上级地区；输入中文和英文均可搜索。中文输入法组合中暂不请求，停止输入约 300 ms 查询，回车立即提交。取消、切换查询和离开面板后，迟到响应不得覆盖当前结果。错误保留原输入和当前地图，并提供重试。真实空内容不添加示例点。

## 数据和供应商

`BrowseDestination` 记录供应商、外部 ID、名称、国家地区、中心、可选范围、来源归属和保存模式；内部 city ID 可为空。`selectedCity` 仅代表真实目录项，`selectedDestination` 独立存在。`renderCity` 是既有地图接口的临时显示适配，不写城市目录或业务数据库。

外部目的地使用现有 `/v1/me/map-content` 的视口范围读取；没有内部城市时不传 `cityId`。旧的城市专属接口仍要求真实城市 ID。返回 Now、面板或键盘变化沿用原地图实例和当前视口。

海外通过 Mapbox v6 Temporary 地理搜索，不加当前国家或视口的硬过滤。Temporary 结果只用于当前交互，不落持久缓存、最近目的地对象或数据库；最近查询只可保留用户输入文字。Mapbox 搜索结果仅配合 Mapbox 地图，国内候选不能转给高德显示。来源依据：[Mapbox Geocoding API](https://docs.mapbox.com/api/search/geocoding/)。

Android 国内搜索使用现已包含的高德搜索 SDK 和 Android Manifest Key，不需要网页 Key。首次同意后才调用 SDK；搜索地名不获取设备位置。原生结果明确为 GCJ-02，Dart 进入现有内容坐标边界时转换为 WGS84，高德渲染边界再执行对应显示转换，不改变持久内容坐标。依据：[高德地理编码](https://lbs.amap.com/api/android-sdk/guide/map-data/geo)、[Android 隐私合规说明](https://lbs.amap.com/api/android-sdk/guide/create-project/dev-attention)。

国内地图复用 Civu 的原始自定义样式文件，抑制底图 POI；Birdtie 获准内容、主动搜索和其他业务图层保持独立。样式加载失败有重试状态，不悄悄改用另一份默认底图。新 Key、样式和坐标对齐仍需同一 APK 的实际手机验证。

## 地图内容失效

身份变化同步撤销旧内容和授权，随后在本轮监听结束后合并一次当前身份、当前视口读取。旧账号响应不得重新填入当前地图。

已证明属于单资源的封面不存在或内容版本变化，只撤销该资源并安排有界重新验证；未知权限错误、身份代次变化继续全局失效。短暂网络故障可保留仍在原授权期限内的内容，不能延长租期。每条内容独立解码，坏项不拖垮正常项；全批异常必须显示错误，不能伪装成零条内容。
