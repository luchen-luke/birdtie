# Now 统一动态编辑器：2026-10-15 用户新增要求

本规范接续原 `BT-FIX-NOW-UI-001`，保留既有迁移、媒体、位置、权限和真机修复，不另建任务队列。当前新增范围处于实施中。Civu 仅只读参考，完整来源与 GitHub 对照见 `docs/testing/evidence/civu-native-adaptation-20261015/civu-unified-editor-source-audit01.md`。

## 用户结果与固定规则

普通动态和串文使用一个内容条目结构、同一编辑器及 Now 原输入框。默认一条，只有点击“再接一条”才增加；一条按普通动态展示，多条按串文展示。删除独立串文类型入口，不增加类型选择页。多图或多个正文段落均不自动拆成多条。

Now 统一创建入口在当前主面板展开动态编辑状态；当前文字和附件进入第一条，文字是正文而非标题。打开已有动态、逐条修改和继续追加也进入这个编辑器。借鉴 Civu 的条目、活动条目和稳定排序身份，不复制整个 screen、路由、全局 store 或账号与媒体接口。

每条支持纯文字、纯媒体、正文加媒体；标题、城市、地点和旅程均可省略。每条独立关联零到多个地点，可以跨城市。没有明确选择时，不继承浏览城市、设备位置或上一条的位置。公开地点或旅程不赋予内容额外可见权限；串文不自动生成旅程、路线或连接线。

## 编辑和提交

逐条编辑、追加、删除、排序和草稿恢复均保留。既有内容使用原 ID 和 revision，不复制为新动态再替换，因此原链接、点赞、评论和分享关联继续存在。历史成员位置不重写；当前展示顺序独立保存，删除单条与撤回整串在预览和最终动作上明确区分。

空白的新条目不发布。上传中、失败或恢复后需重选的材料必须保留可见状态并阻止提交，不能过滤为空后发布其余内容。原始未上传媒体不进入持久草稿；恢复后保留需重选占位，只有用户明确移除才能清除阻塞。失败保留文字、顺序、位置和材料状态，未知提交只查询原 operation，不换 ID 重复创建。

公开发布及公开修改必须先展示准确内容、条数、位置、媒体、删除项和受众，再由用户明确确认。自然语言、选材料、位置选择或草稿恢复都不自动公开。已公开媒体可在明确保留语义下沿用；旧私人导入媒体没有自动公开许可。

## 验收边界

一次关联批次验证：单条纯文字无位置；单条纯媒体无标题；多条混合媒体；不同条目不同城市；发布后追加保持 ID；逐条编辑和删除；排序和草稿恢复；上传失败重试与原操作恢复；返回 Now 保留地图和面板状态；权限校验及地图不泄露不可读内容。

使用直接相关单元／组件和原生事务测试，关联修改合批编译，正常字号、不录屏。新增合同和统一编辑器使用新构建验收，旧 APK16 结果只证明之前已实现的流程。未实际运行的验证记录 NOT_RUN；源码阅读、静态页面、编译和部分测试均不替代完整发布链路。

适用 UX-CHECK-01 至 16 中的稳定实体、同一领域动作、地图与输入状态独立、权限／具体版本批准、异步退休、中文文案、移动键盘和真实验收要求；用户已取消大字号专项，不重新加入。


## 2026-10-19：内容优先与默认串文顺序线

用户在原设计会话明确要求动态为主、原输入框评论/回复、关联地点完整分页及旅程入口，随后明确要求默认显示合法串文顺序线。当前增量以 [内容优先规格](BIRDTIE-NOW-CONTENT-FIRST-2026-10-19.md) 和 [默认路线补充](BIRDTIE-NOW-CONTENT-ROUTES-2026-10-19.md) 为准，接续 BT-FIX-NOW-UI-001。该要求覆盖本文较早的地点聚合主投影、仅选中后显示线与不增旅程入口的冲突描述，历史内容保留。

每条原 Moment 与合法关联/锚点独立，内容时间采用首次发布或已知历史创建来源；同坐标不合并、不移坐标。默认线只连权威相邻且双方当前获准的已加载节点，缺失/无定位/撤权节点留下断点。私人 Journey 与明确批准的公开版本分开；点击旅程不公开计划。Now 继续只有一个输入框，各评论、回复与原会话草稿隔离，沿用现有领域写入与未知结果恢复。

适用 UX-CHECK-01/04/05/06/07/08/09/10/11/12/13/14（正常字号）/15/16；继续保留78号地图生命周期修复和原任务证据。本增量正在实施，新代码测试与构建尚未运行，不能沿用78号真机结果宣称新功能验收完成。Web与TalkBack仍按用户本轮范围延期，未授权本增量生产部署，不录屏。
