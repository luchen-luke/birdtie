## 1. 明确结论

**当前 BirdTie 有较多可复用的底层能力，也已有部分真实模型与地图流程跑通，但仍未达到消费产品验收标准。** 用户指出的布局、面板、空态、入口和操作问题有实际证据；不能用单元测试数量或历史任务 DONE 抵消这些问题。

唯一执行队列有 **256 项：DONE 180、PARTIAL 14、TODO 47、BLOCKED 14、IN_PROGRESS 1**，合计 **76 项尚未全部完成**。IN_PROGRESS 为 `BT-V5-AIR-009`。DONE 是原任务范围的历史状态，不是产品完成 70%，也不是已上线 180 个功能。

其中 P0 共 150 项，仍有 **29 项未全部完成**：7 PARTIAL、12 TODO、9 BLOCKED、1 IN_PROGRESS。

近期 Now 30 条与地点/Agent 成长 26 条合计 56 个来源需求，映射到已有 149 个任务，不另加 56 个执行任务。**两包及 UI 修复整项仍为 PARTIAL。** 当前 Closed Pilot 和 Consumer Beta 不具备放行证据。

本次没有启动测试、构建、迁移、付费模型调用、真机操作或发布，没有修改原队列与产品源码。已补充 `AGENTS.md` 的验证频率和完成汇报口径。完整明细见本报告附录目录 `audit-2026-10-09/`。

## 6. 为什么之前有些清单没有完成

1. **主线曾被收窄。** 早期 V4 主要组织围绕社交、活动与 CSSA 试点。用户后续要求的单人探索、旅程、主题地图、导入和真正自然语言 Agent 没有随底层社交能力自动产生；后续聊天已明确修正主线，但这些实现仍存在真实缺口。
2. **对账不等于实施。** 56 个来源已映射到 149 个旧任务，也写了大量报告；完整包却仍 PARTIAL。许多生活功能仅挂到原 AGE/Context 基础，不能因基础已 DONE 就称旅程或主题地图完成。
3. **底层进展与消费验收没有绑定。** 同域代码、契约或局部用例完成后，视觉、手势和真实使用状态没有一并完成。API33/APK32 已验证若干返回链，但同一版仍有双空态和冷首击失败；这是交付质量缺口。
4. **范围不断追加，核心任务持续积累增量。** 当前 AIR009 仍 IN_PROGRESS，历史完成数未明显变化，不代表最近没有工作；也说明“大范围增量和证据一直累积”不足以给用户一组清楚、可验收的阶段结果。应以原 ID 的小型完整用户流程收口，不另建队列。
5. **有限实现被容易误解为通用能力。** “地址/营业时间”追问、闭集口味记忆、PNG/JPEG 保存均有进展，但不等于通用多轮、全面 Agent 学习或完整附件。
6. **外部门禁确实存在，但不能概括所有遗漏。** 真实 IdP、生产环境、组织/活动供给、账号服务恢复等影响相应上线或真实调用。语音、统一草稿、ThemeMap/Journey、控件布局等本地工作不应一并归为等待外部条件。

不能据当前材料断言每一项历史未完成的唯一根因，也不能称所有旧 DONE 都是假完成；能够确定的是，上述交付范围与验收层次没有被清晰、及时地呈现给用户。

## 8. 下一阶段必须按什么顺序完成

以下是原队列的执行与验收视图，不是新增 backlog，也不在本次自动领取任务。

1. **先收口 Now 的页面结构。** 同批处理顶栏、控件、探索区域、唯一面板、唯一输入、键盘、重复空态和首击失效。用既有原型与当前内容约束落实真实画面，先完成一组可验收首屏和键盘场景。
2. **收口基础 Agent 流程。** 自然语言→站内/获准外部事实→有来源回复与可点实体→同一地图结果→追问→切换/返回。明确无匹配和失败；修复字段答复矛盾。账号未恢复时完成本地路径与定向测试，不重复付费请求。
3. **收口地图中的内容与作者。** 地点→动态→作者→TA 地图→逐层返回；完成当前作者范围客户端、权限重读、聚合分页和恢复。合成验证数据与真实供给分开标注。
4. **补齐用户已经要求的生活操作。** 统一材料与草稿、语音、收藏整理及上图、真实路线、主题地图、旅程和外部清单导入。保留已做的活动/聊天，按真实接口依赖分批交付，不把每个能力改成独立表单。
5. **扩展 Agent 成长并完成交付环境。** 将有限记忆扩展为可控制、可纠正、可删除且实际被下一轮使用的能力；并行处理 Civu 保全与迁移、全球上传、生产认证/部署等独立条件。全部上线门槛到发布检查点核验。

每批的结果应是“原需求 ID + 实际画面/操作 + 当前通过范围 + 剩余缺口”，不能只汇报测试数量。当前视觉审查失败项完成前，不能再次称页面达到消费验收标准。

## 9. 日常验证规则已落入仓库

- 小项只跑直接相关单元测试，必要时含 widget，验证所改流程；不固定跑整个 Flutter/Go、analyze/vet/build、数据库整检。
