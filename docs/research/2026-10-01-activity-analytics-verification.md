# 试点活动漏斗验收（BT-ANA-001）

日期：2026-10-01。环境：本地 PostgreSQL、Go API、Android 真机 `c641566b`，开发预览包。

- 迁移 `026` 增加活动级事件表，只记录活动、事件、入口、时间及报名/收藏的幂等键；不记录用户 ID、手机号、查询语句或精确位置。
- Flutter 在 Now 和 Agent 展示活动时记录会话内首次展示，在真实详情加载后记录打开；报名与收藏成功时由 Go API 记录转换。组织 owner/admin 的中文“活动数据”页展示活动总数和入口明细；普通成员读取返回 403。
- `automation/verify_activity_analytics.ps1` 建立并清理一条合成活动，验证客户端不能伪报报名/收藏，非法来源被拒绝，非管理员无法读取；示例试点报告为展示 1、详情 1、报名 1、收藏 1。附近来源对应展示与收藏，智能体来源对应详情与报名；重复报名和收藏没有重复转换事件。脚本最后删除该活动及其全部测试事件。
- 真机安装新版 APK 后，Now 首屏展示合成组织活动，数据库出现 `impression|now`；打开活动详情后出现 `detail|now`。管理员组织工作区能看到“活动数据”页及中文入口明细。截图：[真机组织活动数据](evidence/2026-10-01-activity-analytics-device.png)。
- `go test ./...`、`go vet ./...`、`go build ./...`、`flutter analyze`、`flutter test`（53 项）与 Android debug APK 构建通过。

统计值是原始事件次数，不等于独立人数。不同会话可以重复增加展示；客户端报告的入口只用于近似归因。开放的查看事件接口目前没有独立的流量防刷机制，因此对外发布的试点结果仍需人工校对。地图瓦片 403 时，Now 使用公开活动列表，仍可记录列表展示与详情打开。
