# 活动通知验收（BT-NTF-001）

日期：2026-10-01。环境：Birdtie 本地 PostgreSQL、Go API、Android 真机 `c641566b`，开发预览包。仅使用本地虚构组织、账户和活动。

## 实现

- 已发布活动改期或换地点时，在活动更新的同一数据库事务中给 `going`/`pending` 参与者写入收件箱通知；取消活动同理。未报名的组织管理员没有收到该活动通知。
- 临近开始提醒由 API 启动和每五分钟的任务触发；同一参与者与活动只写入一条。改期后删除旧提醒并为新开始时间重新生成；取消后删除过期提醒。
- 收件箱项目携带 `targetActivityId`，点击后标记已读，读取该活动公开详情。取消活动的详情仍可打开并显示“活动已取消”。

## 验证

`automation/verify_activity_notifications.ps1 -KeepTestData` 对活动 `765d4871-14b5-4858-a734-b5a147a430cd` 逐项输出 PASS：发布与报名；提醒连续运行两次只保留一条；改期通知及提醒重新安排；地点变更通知；已读状态、活动链接和收件人范围；取消通知、详情状态及取消后的提醒清理。该脚本默认自动清理自己的合成活动，`-KeepTestData` 用于真机检查。首次使用了不存在的本地地点 ID 而在地点变更请求收到 404，已改为已发布的北区测试体育馆并重跑全流程通过；失败运行的合成活动已经从本地库删除。
