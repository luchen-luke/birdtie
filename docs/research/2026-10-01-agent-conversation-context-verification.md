# Agent 对话上下文验收（BT-AGT-004）

日期：2026-10-01。范围：登录任务持久化、匿名会话追问、地图区域继续搜索。

## 修正

- Agent 任务继续请求沿用同一个任务 ID，保留类别、时间、地点范围和前一次真实活动 ID；`currentQuery` 记录当前轮输入，让重新打开任务显示最近一次查询而不是初始问题。
- “搜索此区域”作为当前轮真实用户消息发送。已有活动任务会继承之前的类别和时间，传入的新地图范围替换旧范围。
- 匿名会话的本地任务 ID 不会发送给服务端；区域搜索将初始问题与“搜索此区域”合并，并传真实 `mapBounds`，保证同样的筛选语义。
- 侧边栏“新建对话”清空当前任务上下文；最近任务保留，登录任务重新打开时按当前公开权限重新查询。

## 验证

- Go 意图语料新增“带上下文的区域搜索”和“匿名合并区域搜索”；`go test ./...`、`go vet ./...`、`go build ./...` 通过。
- Flutter 测试新增匿名区域请求不发送 `local-*` ID、控制器传入真实“搜索此区域”消息并保持当前任务 ID。`flutter analyze` 无问题；完整 `flutter test` 42 项通过；debug APK 构建和真机覆盖安装成功。
- 本地 API 登录集成：第一轮“帮我找周末的羽毛球活动”返回 2 个活动；第二轮同任务 ID 发“搜索此区域”及范围，仍为 `badminton/weekend`，返回 2 个范围内活动；重新读取任务时 `query=搜索此区域`，任务 ID 和 ResultSet ID 与第二轮一致。
- 匿名合并区域请求返回 HTTP 200 和 2 个范围内公开活动，无服务端任务 ID。前一轮真机两轮交互和无遮挡对话截图见 [Now Agent 真机验收](2026-10-01-now-agent-composer-device-acceptance.md)。

## 限制

- 匿名对话上下文仅在本次客户端会话内保存，关闭应用后不可作为服务器任务恢复；界面不声称匿名历史持久化。
- Mapbox 瓦片权限 403 使真机无法完成拖图后的区域搜索视觉验收；API 范围过滤和客户端请求边界已分别验证。
