# Agent 意图路由验收（BT-AGT-001）

日期：2026-10-01。范围：Birdtie 本地开发数据库、Go API 和 Flutter 客户端。

## 实现

- `ParseMVPIntent` 将中文优先的请求归一为找活动、找组织、找地点、区域发现、继续筛选、比较结果和创建活动；保留时间、地点、类别、距离条件。无法识别或缺少上下文时明确返回原因。
- 活动、地点、组织分别查询现有公开数据。组织因没有城市字段，仅在当前城市存在仍可发现的公开活动时进入结果；组织认证状态单独呈现，不把未认证组织标成已认证。
- 比较只使用前一次搜索返回的稳定活动 ID，并再次检查这些活动是否仍可发现。创建活动只指向拥有所有者或管理员权限的真实组织工作台，不自动生成或发布活动。
- Flutter 结果页显示组织和真实空结果，中文文案为主。匿名用户的合并追问仍可保留原活动类别和时间条件。

## 验证

- Go `go test ./...`、`go vet ./...`、`go build ./...`：通过。
- Flutter `flutter analyze`：通过；`flutter test`：39 项通过。
- 本地 API 对本地测试供给：周末羽毛球 2 个；公开组织 1 个；无匹配地点 0 个；无范围的“搜索此区域”、无上下文的“近一点”和“比较”均给出明确提示。
- 用本地开发账号连续请求“帮我找周末的羽毛球活动”→“近一点的呢？”→“比较前两个”，任务意图依次为 `FIND_ACTIVITY`、`REFINE_RESULTS`、`COMPARE_RESULTS`；每次只返回 2 个真实活动。重新读取任务可恢复比较结果和中文答复。

## 边界

- 本地活动和组织均为明确标记的测试供给，不代表 Aberdeen 已有真实合作方。
- 地点按已发布地点的名称、摘要和类别作文字匹配；无数据时返回 0。附近一词没有设备定位时只代表当前城市，若要指定地图范围须传入 `mapBounds`。
- AgentResponse、ResultSet、动作入口和地图效果的正式结构由 BT-AGT-002 接续；本任务使用现有响应结构，未声称已经有自动发布能力。
