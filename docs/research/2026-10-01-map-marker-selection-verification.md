日期：2026-10-01（Asia/Shanghai）

## 实现

- 地图使用 `activity:`、`place:` 等稳定实体 ID；聚合 ID 由排序后的成员 ID 构成。活动、地点、社群、人员和聚合分别有不同形状/颜色的语义标记，选中项从聚合中拆出并提升显示层级。
- 原生 Mapbox 标记按实体 ID 和内容指纹增量创建、更新、删除。拖图只重新计算投影，不替换现有选择。
- 点击聚合直接列出成员，避免原先盲目放大后成员 Pin 移出可视区域。成员选中后收起列表，只保留轻量 Entity Card。闲置状态的地点也进入卡片实体映射。
- 地图活动状态在标记列表使用中文标签。
