# 我的活动真实数据验收（BT-PLN-001）

日期：2026-10-01。使用本地测试数据库和 Android 真机。

## 实现

- `GET /v1/me/participations` 返回当前 Person Account 的真实报名摘要。结束状态由服务端活动起止时间、取消状态推导，并对不可见活动隐藏标题。
- “我的活动”从报名、收藏和个人提醒三个独立接口加载，分为“即将参加”“收藏的活动”“已结束”“个人提醒”。“个人提醒”明确说明不代表已报名；取消报名不会误留在“即将参加”。页面打开和下拉刷新会重新读取服务端数据；详情报名变化会刷新报名列表。

## 验证

- 本地 API 返回 1 条 `going/upcoming` 活动；临时把该本地测试活动日期移至过去后，接口返回 `going/completed`，随后恢复原活动日期并确认仍为未来。
- Flutter 组件测试覆盖 `going`、`pending/completed`、收藏和个人提醒的分区与文案。
- 完整 `flutter test` 44 项通过，`flutter analyze` 无问题；`go test ./...`、`go vet ./...`、`go build ./...` 通过，debug APK 构建成功。
- 真机覆盖安装后，登录状态下“我的活动”显示周六测试活动“已报名 · 即将开始”；强制关闭并重启应用，再次打开该页，活动和状态仍在。[重启后截图](evidence/2026-10-01-my-activities-after-restart.png)。

## 边界

- 目前真机使用明确标注的本地虚构活动；真实组织供给仍需后续试点接入。
- 活动详情的完整价格、资格、导航和分享由后续详情任务处理；此任务只验收计划分区和持久化显示。
