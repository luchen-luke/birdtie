## 已验证

- 区域概览接口与活动搜索共用公开资格条件。真实 API 查询在阿伯丁测试范围返回 2 条活动和 `badminton: 2`，范围外和无匹配时间均返回 `status: empty`、空数组；非法或缺少范围返回 400。概览响应中的两个活动保留数据库 UUID，可直接用于地图 Pin。接口没有用客户端标题关键词推断分类数量。
- Flutter Now 通过同一概览响应取得计数和活动实体；地图移动回调不请求数据，初始有效视野或明确的“搜索此区域”动作才读取快照。旧请求不能覆盖新范围的响应。未配置 API 时不再进入羽毛球本地演示查询。
- 真机安装并启动新 debug APK。Mapbox 资源仍返回 403，真实视野无法初始化，页面清楚显示地图不可用，并通过公开活动搜索 API 展示当前城市的近期活动。两条本地开发种子活动明确标记“本地测试”和“本地开发示例”。点击第一条后，真机打开包含主办方、地点、当地时间、介绍和来源的详情预览。
- 开发种子的活动、场地、主办方、来源文案已调整为中文优先，Go 活动时间按城市时区生成中文日期和星期。活动是虚构的本地测试数据，不能作为阿伯丁真实供给验收。
