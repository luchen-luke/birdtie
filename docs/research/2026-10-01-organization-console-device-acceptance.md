日期：2026-10-01（Asia/Shanghai）  
设备：ADB `c641566b`，Birdtie Preview debug APK  
后端：本机 Go API `127.0.0.1:3693`，本地 Compose PostgreSQL

## 覆盖范围

1. 通过本机测试登录创建 `Birdtie Device Pilot` 学生社团，创建者成为 OWNER。初次创建后弹窗关闭触发 Flutter 断言，已修复弹窗状态更新与输入控制器销毁时序；重新安装后组织工作区、组织活动管理入口可正常打开。
2. 控制台显示组织名称、活动列表和发布入口。表单支持标题、已发布地点、分类、介绍、阿伯丁本地开始/结束日期时间、可选人数和可见范围；校验在表单和后端均存在。英国夏令时跳过/重复的 01:00 不接受模糊转换。
3. 真机填写 `Birdtie Device Badminton`，预览地点与本地时间后点击确认发布。控制台显示“已发布 · 公开可见”；本地数据库显示 `published`。随后从 UI 取消，数据库 `cancelled_at` 已写入。
4. 发现长地点名造成 28 像素右侧溢出，加入展开和单行省略后重新安装；第二次表单显示正常。`Birdtie Three Minute QA` 再次由真机发布，数据库确认 `published`。从开始填写到发布的设备时钟跨度约两分钟，包含一次因操作节奏造成的时间选择弹窗中断；这只验证一次熟悉流程，尚不是对新管理员的正式可用性计时研究。
5. 两条真机测试活动已从本地数据库删除，组织及测试账号保留用于后续本机验收。未向外部环境发布。
