# 活动报名与真机重启验收（BT-RSV-001）

日期：2026-10-01。环境：本地测试数据库、Go API、Android 真机 `c641566b`；活动为明确标注的本地虚构测试活动。

## 实现

- `activity_participations` 一人一活动唯一行；加入、取消、重新加入使用持久化状态。加入时锁定活动行并检查公开发布状态、城市状态、取消、结束/过期、屏蔽关系和容量。`going`/`pending` 重复加入不增加记录。活动计划与报名仍为两个独立概念。
- API 提供当前用户报名读取、加入、取消；拒绝 Organization Account 作为参与者。无报名、重复报名、满额和活动关闭都有明确响应。
- 活动详情每次打开均重新读取活动和当前用户报名状态；中文按钮随服务端状态变化。Now 的活动结果、Pin 详情和地图不可用时的公开活动列表均可进入此详情。

## 验证

- 本地 API：`GET` 无报名为 `200/data:null`；首次加入 `201/going`；重复加入 `200/going`；取消 `200/cancelled`；重新读取仍为 `cancelled`；重新加入 `201/going`；再读取仍为 `going`；不存在活动 `404/not_found`。临时设置本地测试活动容量为 1，第二名用户加入返回 `409/activity_full`；临时取消另一测试活动，加入返回 `409/activity_unavailable`。两处测试数据字段均已恢复。
- Flutter 活动详情测试覆盖从服务端读取已报名、取消、重新报名；完整 43 项测试通过，`flutter analyze` 无问题。`go test ./...`、`go vet ./...`、`go build ./...` 通过。debug APK 构建并覆盖安装成功。
- 真机登录本地测试账户，在活动详情先看到已报名；取消后按钮改为“报名参加”，关闭重开详情仍然如此；重新报名后强制关闭并重启应用，详情仍显示“你已报名”和“取消报名”。[取消后截图](evidence/2026-10-01-rsvp-cancelled-device.png)；[重启后截图](evidence/2026-10-01-rsvp-after-restart-device.png)。
