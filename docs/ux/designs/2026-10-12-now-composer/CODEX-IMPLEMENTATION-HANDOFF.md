## Apple 玻璃材质的实施口径

正式参考：[Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)。已读取官方 Materials 文档：Liquid Glass 用于浮在内容上的导航和控件；文字较多的侧栏/弹层宜用 regular，内容层使用清晰的标准材质。效果适量，并适配减少透明和增强对比度。

据此为 BirdTie 落地：顶栏控件、浮起输入框、侧边导航与联系展开区体现背景透色、表面厚度、轻微边缘高光和柔和深度；回答正文、关键字段、图片和头像保持锐利，长文提高底色遮挡。地图道路文字不能透过来干扰输入和阅读。采用共享材质 token/组件，覆盖浅色、深色、焦点、按压、展开/收起及辅助功能设置，避免不同区域各造一套玻璃参数。

原型里的 CSS 透明度、blur 和阴影是浏览器演示值。正式实现按现有 Flutter/目标平台能力选择合适材质与降级，截图确认实际观感；不得宣称普通透明白底或 CSS 模糊已等同 Apple 原生 Liquid Glass。保持主体地图清晰，模糊限制在控件背后的局部区域；合并当前玻璃性能修正，避免整张地图模糊、多层重复采样、常驻动画和地图重建。读取/后台/减少动态的状态恢复继续有效。

接续本仓 `docs/product/NOW-AGENT-MAP-WORKSPACE.md:7` 的 `NowUiTokens/BirdtieSurfaceTokens` 与局部玻璃执行合同，以及 `docs/product/BirdTie-Interaction-Quality-Codex-Plan-2026-10-04.md:57` 的 Apple 参考使用要求；在当前性能工作基础上核实材料实现，不另建不受约束的玻璃系统。
