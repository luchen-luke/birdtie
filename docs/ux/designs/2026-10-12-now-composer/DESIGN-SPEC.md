## 目标与承接

面向中文为主的留学生用户：在地图上表达需求、组织材料、检查结果，再继续编辑或进入同一实体详情。保留一个稳定地图、一个主面板、一个输入框，地图相机、选择、会话与键盘独立保存。右侧以当前稿的联系人列表、最近联系人和消息通知为同一联系区域，不机械沿用旧 V4 布局；地图标记不表示用户实时位置。左侧会话与导航使用全高侧边栏。

参考截图采用轻盈输入、锚定菜单、开放正文与紧凑来源；结合 BirdTie 的地图工作区、实体卡和草稿流程。模式标签只在明确的“动态草稿”“活动草稿”等上下文出现，不照搬模型选择器或语音通话入口。

## 布局与视觉

手机主面板左右、底部贴屏，外边距为 0，仅顶部圆角 24；内容左右内边距 16。背景覆盖系统手势区，交互内容在内部避让。输入、左右展开区与地图控件采用局部玻璃；主阅读面板提高底色遮挡，文字与头像本身不模糊。减少透明效果时使用清晰底色。

空态 composer 最小高 56：左侧加号、中间“想探索什么…”、右侧麦克风。聚焦、实际换行或带材料后，上方正文、下方工具行，基准约 120，可随文字增长；工具行加号在左，明确模式在中，麦克风和有字才出现的深色上箭头在右。本稿沿用已选城市作地域上下文，不显示模型选择。按实际可用宽度、字号与行高测量换行，不用字符数量代替；字多时正文内部滚动，主操作始终可达。

普通回答不套大卡边框；用户消息为右侧浅灰气泡，正文按现有 token 为 15px、行高 1.5、常规字重；输入 16px，标题 18px，实体名称 16px，动作 14px，辅助文字 13px。独立回合留白 16–20，不用粗体满屏强调。一般断言旁放紧凑来源；单地点事实只呈现一张地点卡与一个来源入口，保留完整地址和冲突，不重复正文、域名胶囊和“全部来源”。

短实体结果按内容自然高度展开，正常竖屏优先控制在可用高度约 35–45%；长回答先摘要，用户主动展开后约 70–85%，仍是同一面板。阅读区滚动、composer 固定底部；“回到地图”收短面板，保存原阅读位置，重新展开继续阅读。这些比例不作为大字体或横屏硬上限。

## 状态与可点击行为

| 状态 | 行为与退出 |
|---|---|
| idle | 仅紧凑输入，无内容时不显示拖拽柄；点击进入编辑。 |
| editing | 唯一输入扩为两层；保留光标、候选字和草稿。收键盘不清空结果；清空内容且失焦后恢复单行。 |
| attachment | 加号上方锚定菜单：拍照、照片、文件；分隔后动态、活动、旅程、主题地图。选择材料后显示可移除预览，取消返回原草稿；选择创建只准备草稿。小屏菜单限高滚动，超出空间转为同内容模态，冻结底层交互。 |
| @ | 输入 `@` 出现好友、地点、已保存对象的上下文选择；选中形成可移除引用，取消只关闭候选。引用帮助理解对象，不切真人收件人、不发送、不扩大可见权限。候选仅来自本人有权读取的对象。 |
| loading | 提交后保留用户消息、稳定结果与地图，显示“正在整理…”和取消；取消退休当前请求，迟到结果不得覆盖新任务或输入。 |
| shortResult | 展示短回答或实体卡，点卡聚焦同一地图对象；来源、详情、更多操作返回后恢复选择与输入。 |
| expanded | 点击“展开阅读”或拖动展开；提供明确收起入口，不只依赖手势。用户阅读旧内容时新回合不强制滚到底。 |
| draft | 当前草稿可逐项编辑，显示身份、对象、受众、时间地点和费用等关键后果。“保存草稿”与“发布”分开；演示发布只显示确认预览及边界说明，绝不回报“已发布”。 |
| empty | 显示“暂未找到符合条件的内容”，提供修改条件或选择范围；保留输入与原地图，不用空结果替代服务错误。 |
| error | 确定读取失败提供重试、修改；权限阻断说明当前可用路径。外部提交结果未知显示“正在核实”，先读取原操作状态，不能盲重发。 |
| voice | 原输入框内显示录音计时、波形、停止与取消，停止后就地处理并恢复可编辑文字，无日常录音弹窗。本稿只模拟，不采音、不自动发送；取消回到原草稿。好友聊天的录音则停止在语音消息预览，等本人明确发送。 |

返回顺序为临时菜单/来源 → 键盘 → 当前展开面板 → 原地图上下文；每步保留草稿与阅读位置。城市、账号、组织、收件人或任务变化必须隔离上下文并退休旧异步结果；不能携带旧批准提交新版本。好友对话继续使用原明确收件人路径，与 Agent 上下文引用区分。

## 移动端与能力边界

由 `NowWorkspaceLayout` 唯一消费 IME 遮挡；不能同时重复应用自动缩放和 bottom inset。键盘开合不重建地图或额外搜索。输入法候选未确认时不发送；回车默认换行，有发送动作也须通过同一校验。已有 240 UTF-8 字节限制需完整保留超长草稿、明确提示缩短，不能静默截断。

检查 360×800、390×844、430×932、窄横屏与 1.3/2.0 系统字号：容器增长、文字换行、内容可滚，先压装饰留白；主要触控区域至少 48，保留可读语义标签、焦点与关闭入口。原型尺寸切换只能检查布局，不能证明原生键盘、读屏、性能或生产恢复通过。

原型地图、头像、人物、实体、材料、来源和操作全部使用演示数据，不接服务、不外发。正文仅留在本次预览内存；跨次只记界面状态，不存输入正文。地址示例 `Shiprow, Aberdeen` 来自 10/08 旧原型，显示“演示资料”，不代表此次核验。图片预览继续说明“助手暂不读图”。现有源码已含图片草稿及语音接线；截至读取的 integration 报告顶部，本机 Whisper 09 中文一次真机识别为 PHONE_PASS，英文等待本人结果、混说 NOT_RUN。本稿模拟语音不替代这些证据；`@`、拍照、通用文件及旅程/主题地图创建仍是本次设计扩展。
