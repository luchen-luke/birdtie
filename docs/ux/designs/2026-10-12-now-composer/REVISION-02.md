# Now 设计稿第二轮调整

2026-10-12。仅更新可点击原型与设计说明，使用演示数据；不接服务、不修改生产代码或原任务队列。本文补充 [首版说明](DESIGN-SPEC.md)，以本轮用户反馈为呈现依据；旧 V4 的布局快照不再限制新稿，但身份、权限、单地图、单输入框及异步恢复规则继续有效。

## 已确定的呈现

保留已认可的输入框、开放回答正文、短结果与同一面板长文阅读。左上“会话与导航”从左侧展开全高 drawer，基准宽约 310，按小屏与字号适配，展示会话和原导航；取消此前向上弹出的导航面板。关闭后恢复原地图、草稿和阅读位置，遮罩不允许点击穿透。

右侧作为统一联系区域：点击“联系人”向下展开当前有权查看的联系人列表，显示姓名、已有会话摘要、时间及未读状态。没有会话时明确显示“尚未开始会话”；联系人不等于全部消息历史，更多数据按原权限分页。好友与关注关系沿用原区别，不能因为出现于名单就获得私聊权限。

常驻头像明确为“最近联系人”，按最近会话顺序呈现，点击直接进入此人的独立聊天；本轮不引入手动置顶设置。消息与通知在同一区域保留各自入口、未读语义和返回路径；通知打开对应权威对象，不伪装成真人对话。列表、聊天、通知按需切换，避免多层浮窗叠加。

## 聊天与草稿

进入单人聊天持续显示对方姓名及“发给……”提示，由原唯一 composer 承载输入；退出回到来源列表或最近联系人。Now 的 Agent 任务、不同真人会话和不同工作身份各自保留草稿、材料及阅读位置，切换不搬运文字，不自动发送；原型草稿只留本次内存。输入 `@` 只引用获准对象，不切换收件人。切账号、任务或收件人立即退休旧读取、录音和转写回调；旧批准不得复用，私聊不自动进入 Agent 上下文。

## 输入框内语音

点击麦克风后，原输入框内部直接显示计时、波形、“停止”和“取消”；无需另开日常录音弹窗。停止后在同一区域显示“正在转成文字…”，完成后恢复可编辑文字，按原光标位置插入，发送仍由用户点击。录音前文字和选区保留；取消还原，识别失败或无声音时就地提供重试和键盘输入，不清空草稿或静默截断。

退到后台停止采音并退休本次转写；返回显示中断状态及原草稿，不自动重新录音。首次麦克风系统授权、真实服务告知及可能联网处理的明确选择仍按实际能力处理，不用“无弹窗”绕过。好友聊天的麦克风在同一输入框录制语音消息，停止后提供试听预览和明确发送；不自动转写或发送。原型两种流程均为模拟，不采音，不代表真实识别、发送或恢复验收。

## 玻璃分层与检查边界

输入框、侧边 drawer 和右侧展开区域采用局部半透明玻璃、细边界及克制阴影；模糊限于各自表面背后，地图主体、文字、头像保持锐利。回答与关键字段提高底色遮挡，长文优先阅读。深色使用对应语义色与更稳的遮挡；减少透明效果时改清晰底色，减少动态效果时去掉波形和位移动画，仍显示计时与状态。保留现有字号、自然换行和至少 48 的主要触控区。
